# MusicBoard

**공식 저장소: [contentriumkorea/MusicBoard](https://github.com/contentriumkorea/MusicBoard)**

기존 0.1.10 앱의 자동 업데이트를 위해 SONO 주소를 임시로 유지합니다. 앱에서 ‘업데이트 확인’을 눌러 새 MusicBoard 버전을 적용하세요. 새 버전은 공식 MusicBoard 저장소에서 업데이트를 확인합니다.

개발·문의·새 설치 파일은 공식 저장소를 이용해주세요. 이 주소의 배포 파일은 공식 파일의 크기와 SHA-256을 확인한 뒤 복제합니다.
