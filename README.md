# MusicBoard 업데이트 호환 주소

**공식 소스 코드와 새 배포: [contentriumkorea/MusicBoard](https://github.com/contentriumkorea/MusicBoard)**

이 저장소는 구 SONO 업데이트 파일을 보관합니다. 0.1.11 이상 앱은 공식 MusicBoard 저장소에서 업데이트를 확인합니다.
0.1.10 이하에서 예전 SONO 주소로 업데이트 확인이 실패하면 공식 저장소에서 설치 파일을 받으세요.
앱 개발과 이슈 등록은 위 MusicBoard 저장소를 이용해주세요.

복제 작업은 GitHub Actions에서 수동으로 실행할 수 있습니다. 실행하면 공식 배포 파일의 크기와 SHA-256을 확인한 뒤 복제합니다.
